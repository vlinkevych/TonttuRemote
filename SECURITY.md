# Security

If you have found a security vulnerability in Tonttu, please report it privately to **security@tontturemote.app** before publishing anything. Include how to reproduce it and the app version (About page).

You'll get an acknowledgement within a few days and a fix as soon as I have one; beta builds update themselves. If you'd like to be credited in the release notes, say so.

Only test on computers and devices you own.
