How to install Tonttu on Windows

About two minutes from download to controlling your PC from your phone. Windows and your phone’s browser may each show a security message the first time. This guide explains why.

BETA
Tonttu is in beta.Everyday features work, but you may run into bugs or rough edges. Updates install automatically when no phone is connected. If something breaks, tell me.

01Run the installer

Open TonttuSetup-<version>.exe from your Downloads folder.

Tonttu is in beta and its installer isn’t code-signed yet. The app also installs a small system service that lets it control the mouse and keyboard even in windows that run as administrator. Because of this, Windows shows “Windows protected your PC” before installing.

To continue, click More info, then Run anyway.

Next, Windows asks for permission to make changes, because the installer sets up a small service. The publisher shows as unknown for the same reason: the beta isn’t code-signed. Choose Yes.

The installer then shows the licence, lets you pick the folder and installs in a few seconds. On its last page it offers to start Tonttu right away and to allow devices on networks Windows marks as Public (leave that off at home).

02Finish setup

When installation finishes, Tonttu opens a short welcome. It shows what the remote can do and the QR code to scan, and asks whether to start with Windows. Afterwards the app keeps running in the system tray, next to the clock.

03Connect your phone

  1. Connect your phone to the same Wi-Fi network as the PC.
  2. Open the camera and scan the QR code. Tap the link that appears.
  3. On the PC, click Allow to let the phone connect. Only devices you allow can control the PC.

04The browser security warning

If the security certificate isn’t installed yet, you may see a security warning when the remote opens. This happens because the certificate is made by your own computer, not by a company the browser already knows. The connection is still encrypted and stays on your home network.

On iPhone and iPad: tap Show Details, then visit this website, then Visit Website.

In Chrome on Android: open Advanced and select Proceed to … (unsafe).

05Install the certificate Optional

The connection between the phone and your computer is encrypted. The certificate for it is made by your computer, not by a company the browser already knows, so the browser shows a security warning when the remote opens.

Installing the certificate tells the phone to trust your computer. The warning goes away, the connection stays encrypted, and nothing leaves your home network.

Install it once on each phone or tablet.

  1. In the PC app, open Certificate.
  2. Scan the code with the iPhone camera and tap Allow to download the profile.
  3. Open Settings › General › VPN & Device Management.
  4. Tap the Tonttu profile, then Install.
  5. Open Settings › General › About › Certificate Trust Settings.
  6. Turn on full trust for Tonttu. Done.
  1. In the PC app, open Certificate and choose Android.
  2. Scan the code with the camera. If the browser warns about the connection, tap Advanced, then Proceed; the certificate file downloads.
  3. Open Settings › Security & privacy › More security settings › Encryption & credentials. On Samsung phones: Security and privacy › Other security settings.
  4. Tap Install a certificate › CA certificate, confirm Install anyway, and pick the downloaded file from Downloads.
  5. Done. Android may show a “network may be monitored” note: that is its standard message for any certificate you add yourself. Works in Chrome and Samsung Internet; Firefox on Android ignores certificates you add yourself.

06Troubleshooting

The QR code doesn’t open the page
  • Scan with the phone’s own camera app.
  • Hold the phone steady and move a little closer, so the code fills most of the screen.
  • Wait for the link to appear on the screen, then tap it.
  • Still nothing? Type the address shown in the PC app into the phone’s browser.
The page doesn’t load and nothing appears on the PC
  • Check that the phone is connected to Wi-Fi, not mobile data.
  • Make sure the phone and the PC are on the same network. Guest networks often keep devices apart, so use your main Wi-Fi.
  • Check the network settings on the PC. If Windows marks the network as Public, it treats it as untrusted and the firewall stops phones. On the app’s Connect page, choose Mark as Private, or allow phones on public networks in Settings › Network. We don’t recommend allowing public networks.
  • If the PC has both Wi-Fi and a cable, or uses a VPN, the code may use the wrong address. Pick the right one in Settings › Network › Network adapter.
The browser shows a security warning
  • This is expected until the certificate is installed. The connection is still encrypted and stays on your home network.
  • To continue on iPhone or iPad: Show Details, then visit this website, then Visit Website. In Chrome on Android, open Advanced and select Proceed to … (unsafe).
  • To stop the warning for good, install the certificate.
I installed the certificate, but the connection still shows as not secure
  • On iPhone or iPad, make sure you finished every step. Installing the profile isn’t enough: turn on full trust in Settings › General › About › Certificate Trust Settings.
  • Close the browser tab and scan the code again.
  • If the PC’s network address has changed, the old certificate no longer matches. Install the new certificate from the app’s Certificate page.
  • To stop the address from changing, give the PC a fixed address in your router’s settings. This is often called a DHCP reservation.
The home-screen icon stopped working
  • An icon added to the home screen only connects while the phone trusts the certificate: unlike the browser, it has no “continue anyway” button. With the certificate removed, or its trust turned off, the icon opens a blank page.
  • Install the certificate again from the app’s Certificate page, or open the remote in the browser instead: scan the code, continue past the warning, and use it there.
  • On iPhone, a link to a site that has a home-screen icon may open in that icon rather than in Safari. Then open Safari yourself and type the address shown in the PC app.
Windows asks for admin permission
  • Only during installation, so the app can set up its service and let phones through the Windows firewall. After that it starts quietly when you sign in.
