    4. What the software does, and your responsibility

    The software lets a paired device control your computer over your local network. To do that it:

  • runs with your normal user rights. A small helper service that runs with system rights passes the device's input on to windows that run as administrator (such as installers and Task Manager). The service has no network access. Windows' own permission prompts ("Do you want to allow this app to make changes?") can be answered from the device only if you turn that on in Settings, which itself asks for administrator permission;
  • can move the pointer, type, press any key combination, switch and start apps, and lock, sleep, restart or shut down the computer;
  • can send files to the computer and, unless you turn it off, let a paired device download files you have selected in File Explorer;
  • sends paired devices what they need to work: the text around the cursor in the field you are typing in (never password fields), the names of open windows and of the app in front, and, when you ask for them on the device, the clipboard and files;
  • creates a local certificate authority on your computer, which you can install on your device so the connection is encrypted and trusted. It is limited to home-network addresses and cannot be used to vouch for websites on the internet.

    • Anyone holding a paired device can control your computer while the app runs. You are responsible for:

  • which devices you pair, and removing or banning devices you no longer trust;
  • keeping the pairing code and QR code private;
  • the networks you use the software on (home or other trusted networks are recommended; a network Windows marks as Public may allow other people to try to connect);
  • removing the certificate profile from your device if you stop using the software;
  • keeping your own backups. Remote actions such as shutting down can lose unsaved work.

    • Not for high-security systems. The software is not designed or tested for computers where security is critical, such as systems that handle regulated or highly sensitive data, or that control medical, industrial, financial or safety-critical equipment. Don't use it on them.

    Work computers. On a computer managed by an employer or another organisation, use the software only if its IT administrator allows it. It installs a system service and accepts connections from the local network.

    What installing changes. Installing the software adds:

  • a Windows Firewall rule that allows incoming connections to the app on networks Windows marks as Private or Domain. Public networks are allowed only if you turn that on;
  • a Windows service ("Tonttu helper") that runs with system rights, as described above;
  • an entry that starts the app when you sign in, if you choose that option;
  • a local certificate authority on your computer (not installed as trusted on the computer itself; only on devices where you choose to install it).

    • Uninstalling removes the firewall rule, the service and the start-up entry. Consider these changes before installing the software on a computer that holds sensitive information.
