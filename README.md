# Tonttu: Wi-Fi Mouse and Keyboard

Tonttu turns your phone into a touchpad and keyboard for your Windows PC. Scan a QR code on the PC with your phone's camera and the remote opens in the phone's browser, so there's nothing to install on the phone.

Everything stays on your home network: phone and PC talk directly, with no account and no cloud.

## Status

Tonttu is in development. The first beta isn't released yet; when it is, the installer will be on this repository's Releases page.

## About this repository

This repository holds Tonttu's releases and website. The source code is kept elsewhere. Feedback goes through the app itself once the beta is out.
